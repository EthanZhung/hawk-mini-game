# 霍克捕獲遊戲 · Meadow Patrol

以 HTML、CSS 與 JavaScript 製作的繁體中文單機捕獲遊戲。支援滑鼠與手機觸控，角色使用自行繪製的 SVG 圖像。

## 線上遊玩

**遊戲網址：https://ethanzhung.github.io/hawk-mini-game/**

此網址在 GitHub Pages 啟用並部署完成後可用。遊戲為純靜態網站，所有樣式、程式與角色都內嵌於 `index.html`，不需要後端、帳號、API key 或額外套件。

## GitHub Pages 部署

到儲存庫的 [Settings → Pages](https://github.com/EthanZhung/hawk-mini-game/settings/pages)：

1. **Source** 選擇 `Deploy from a branch`。
2. **Branch** 選擇 `main`。
3. 資料夾選擇 `/(root)`，按下 **Save**。
4. 等待 GitHub Pages 部署成功，再開啟上方遊戲網址。

之後更新 `main` 分支的 `index.html`，GitHub Pages 就會重新部署。若頁面尚未更新，請確認 Pages 部署狀態並重新整理瀏覽器。

## 遊戲方式

- 每局消耗 1 個星星鎚，初始提供 10 個；倒數從 60 秒開始。
- 點擊洞口中出現的小豬累積分數與 Combo，避開牧場女孩。
- 擊退三段霍克可取得炸彈；按炸彈按鈕或空白鍵使用。
- 炸彈會對當下全場可受擊目標各造成一次傷害，也會波及女孩。
- 點擊暫停或按 Escape 暫停；切換背景或視窗失焦也會自動暫停。
- 時間結束後查看分數、最高 Combo 與分類統計，可再次遊玩或回到主畫面。

| 角色 | 規則 |
| --- | --- |
| 粉紅霍克 | 1 次命中捕獲，基礎 30 分、Combo +1 |
| 紅色霍克 | 5 次命中捕獲，每次有效命中皆給分並增加 Combo；注意反擊預告 |
| 三段霍克 | 3 次命中捕獲，最後一擊基礎 150 分、Combo +1、炸彈 +1 |
| 飛行霍克 | 1 次命中，隨機獲得固定 300 分或增加 3 秒，不影響 Combo |
| 牧場女孩 | 不可敲擊；誤擊會中斷 Combo 並僵直 0.4 秒 |

連擊計分：先增加 Combo，再計算 `floor(基礎分 × (9 + Combo) / 10)`。一般霍克前四次得分為 30、33、36、39。空擊與自然漏掉目標不斷連；誤擊女孩或遭到紅色反擊會斷連，保留既有分數與最高 Combo。

上述數值是重製版採用的預設規則，不代表原作已確認的內部公式。所有結算數字都由該局事件計算。

## 紀錄與設定

星星鎚、最高分、最高 Combo、累積紀錄、任務獎勵與音效設定保存在此瀏覽器的 `localStorage`。

- 任務獎勵達標後可領取更多星星鎚，每個獎勵限領一次。
- 放棄或意外關閉已開始的回合不退鎚，不支援中斷續玩。
- 無庫存時可查看可領取的任務；也可在設定中確認重設全部本機資料，恢復初始 10 鎚。
- 清除網站資料、切換瀏覽器或裝置不會保留原有紀錄；本版沒有雲端同步或線上排行榜。
- 音樂、音效、支援裝置的震動及降低動態效果可在設定中調整。

## 本機執行

下載或 clone 此專案後，在專案根目錄執行：

```sh
python3 -m http.server 8000
```

接著在**自己的電腦**瀏覽器輸入 `http://localhost:8000`。遊戲無需 npm 安裝或建置。

## 專案結構

```text
hawk-mini-game/
├── README.md
└── index.html    # 可獨立發布的完整遊戲
```

GitHub Pages 的入口為 `index.html`，不需要另外維護下載資料夾。

## 開發檢查

遊戲已通過 Chromium 桌面與觸控模擬的開始、命中、暫停、炸彈、結算、再次遊玩及存檔驗證。核心規則另已完成 30 項自動測試；本儲存庫目前發布的是可直接遊玩的單檔版本。

若需檢查角色行為，可在遊戲網址加入 `?dev=1` 開啟開發面板，操作固定 seed、指定生成、hp、炸彈、時間及回放驗證。一般遊玩不會顯示此面板。
